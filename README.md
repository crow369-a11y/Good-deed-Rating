# Игра «Добрые дела» (Python OOP)

Проект по дисциплине «Языки программирования». Реализация игры с использованием собственного двусвязного циклического списка.

## Структура
- `structures.py` — узлы и циклический список
- `engine.py` — логика игры, раунды, сортировка
- `main.py` — консольное меню, валидация, интерфейс
- `students.txt` — пример файла с фамилиями


## ⚙️ Требования
- Python 3.8 или выше
- Без внешних библиотек (только стандартная библиотека)
- Операционная система: Windows / Linux / macOS
